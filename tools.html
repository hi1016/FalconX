VPN leak notes

A leak test compares your public address, DNS, and WebRTC address. On this demo, compare the IP result with the city you selected in a real client. If they differ, the tunnel is not the path in use.

Password strength

Checked only on this page. The value is not sent anywhere.

Type to check strength locally

Port notes

Port forwarding is enabled per device from the member area on supported cities. This page does not probe ports on any host.

IPv6 check

If a network gives you an IPv6 address while the VPN only covers IPv4, traffic can leave outside the tunnel. FalconX apps disable that path while connected. This browser page cannot toggle it for you.

DNS check

While FalconX is connected, name lookups should go to FalconX resolvers. If a leak test shows your ISP’s resolvers, reconnect with App Guard enabled.
