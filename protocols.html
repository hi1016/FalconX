VPN protocols

Pick the tunnel that matches the network. The app can also choose for you.

WireGuard

The default on open networks. Small codebase, quick reconnects, strong throughput on FalconX-Fast VPN Proxy hardware.

OpenWeb

Wraps the tunnel so it resembles ordinary web traffic. Useful on networks that block uncommon ports.

Shadow Mode

FalconX-Fast VPN Proxy’s own option for restrictive networks, built so VPN traffic is harder to single out.

OpenVPN

Still available when you need a widely supported fallback.

IKEv2

A fit for phones that roam between Wi-Fi and cellular.

How to choose

Leave the app on automatic. Switch to OpenWeb or Shadow Mode only if the first connection fails.
