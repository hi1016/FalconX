What is a VPN?

A virtual private network is an encrypted path from your device to a server you choose.

Without a VPN, the local network can see which servers you contact. With FalconX connected, that network sees a single encrypted session to a FalconX server. Websites see the server’s address instead of yours.

A VPN does not make every account anonymous. Sites where you sign in still know it is you. It does stop a café hotspot from reading the pages inside the tunnel.
